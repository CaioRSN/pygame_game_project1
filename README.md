## 📝 About the Project
This is our first game development project for college, built with Python and the Pygame library and developed entirely in VS Code. 

The game follows a teacher on just another ordinary day, until an invasion of Linux penguin invaders attacks him. His mission? Defeat all the penguins, finish all the minigames, and face the final boss: **"CinSegura"**.

This project was developed as a requirement for the **Introduction to Programming** course.

---

## 🛠️ Technologies Used
* [Python 3](https://www.python.org/) - Base programming language.
* [Pygame](https://www.pygame.org/) - Library used for game logic, physics, and rendering.
* [VS Code](https://code.visualstudio.com/) - Integrated Development Environment (IDE).

---

## 🚀 How to Run the Game

### Prerequisites
Before running the game, you need to have **Python** installed on your machine.


### Step-by-Step Installation

1. **Clone the repository:**
     git clone https://github.com/CaioRSN/pygame_game_project1.git
   
2. **Navigate to the project folder:**
   cd pygame_game_project1\'CIN AVENTURE'\GAME_PROJECT 
   
3. **Install the Pygame library:**
  pip install pygame --- OR ---  pip install pygame-ce (if the version of your python is under 3.13)
  
4. **Run the game:**
  python main.py



## 🎮 **Controls**
A / D: Move character (left and right).
W or Spacebar: Jump.
K: Attack Key
T: Interact with NPCs (when standing nearby).
